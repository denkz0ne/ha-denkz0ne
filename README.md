# Home Assistant projekty

Prehľad mojich Home Assistant integrácií a projektov. Každý projekt má vlastný repozitár, dokumentáciu a vydania.

## Integrácie

| Projekt | Popis | Repozitár |
|---|---|---|
| **BlockFront Stats** | Senzory verejných štatistík hráča, posledného zápasu, počtu online hráčov a stavu služby. | [denkz0ne/blockfront_ha_integration](https://github.com/denkz0ne/blockfront_ha_integration) |

## Inštalácia cez HACS

V HACS otvor **Integrations → ⋮ → Custom repositories**, pridaj adresu repozitára integrácie a vyber kategóriu **Integration**. Potom vyhľadaj a nainštaluj **BlockFront Stats**.
