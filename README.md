# Home Assistant projekty

Prehľad mojich Home Assistant integrácií a projektov. Každý projekt má vlastný repozitár, dokumentáciu a vydania.

## Integrácie

| Projekt | Popis | Repozitár |
|---|---|---|
| **Svetlo v tme** | Ovládanie svetiel a zariadení, harmonogramy a ochrana pred nechceným prepísaním manuálneho ovládania. | [denkz0ne/entity-controller](https://github.com/denkz0ne/entity-controller) |
| **EduPage pre Home Assistant** | Integrácia systému EduPage do Home Assistantu. | [denkz0ne/haos_edupage](https://github.com/denkz0ne/haos_edupage) |
| **Strážca senzorov** | Dostupnosť zariadení a informácie o životnom cykle batérií. | [denkz0ne/strazca-senzorov](https://github.com/denkz0ne/strazca-senzorov) |
| **BlockFront Stats** | Verejné štatistiky hráča, posledný zápas, počet online hráčov a stav služby. | [denkz0ne/blockfront_ha_integration](https://github.com/denkz0ne/blockfront_ha_integration) |

## Inštalácia cez HACS

Pri integrácii, ktorú chceš nainštalovať, pridaj v HACS jej GitHub adresu cez **Integrations → ⋮ → Custom repositories** a vyber kategóriu **Integration**. Potom ju vyhľadaj a nainštaluj.
